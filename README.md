# 🌐 Language Translation Tool

##  Project Overview

The Language Translation Tool is a Python-based application
that translates text from one language to another.

The application provides a simple Gradio interface where users
can select the source language, target language, enter text,
and get the translated result.

##  Technologies Used

- Python
- Deep Translator
- Gradio
- Jupyter Notebook

##  Supported Languages

- English
- Telugu
- Hindi
- Tamil
- Kannada
- Malayalam
- Bengali
- Marathi

##  Features

- Translate text between multiple languages
- Source language selection
- Target language selection
- Simple Gradio user interface
- Copy translated text
- Clear input and output
- Error handling for failed translations
- Empty input validation
